# `linux/ubuntu-white` — Ubuntu White Edition (as-is)

The Ubuntu White Edition layer, copied **as-is** from
`mearvk/Ubuntu.Determinant.Beta.Restricted` `ubuntu-white`, source commit
`0f2694e5f7fe09da1f61ab1cc48e56079cc3336b`.

This is the branding / edition layer (greeting, GTK theme CSS, icons, release
notes, and the `.hsss` edition descriptors), not a boot/kernel/userland OS
component. It is warehoused here alongside the other Linux pieces so an OS
rollout can apply the White Edition look and release metadata.

## Contents

- `README.md`, `INSTALL.md`, `UBUNTU-GRAND-RELEASE.md` — docs / release notes
- `IconGreeting.md`, `IconGreeting2.md` — greeting assets
- `gtk.css` — the edition GTK theme
- `ubuntu-white.hsss`, `UBUNTU-GRAND.hsss` — edition descriptors
- `icons/` — the edition icon set
